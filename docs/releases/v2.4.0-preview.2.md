# Dune Rev 2.4.0 Preview 2 + Dune Materials 0.6.8

## What's new

- Three material layers: background, content and flyouts. Shared blur and softer
  artwork colors bring cards, details, filters and the top bar together.
- Softer highlights and optional fine grain; stronger tint for menus and notifications.
- One shared blur setting in ThemeModifier. Dune Materials uses realtime rendering;
  unavailable or disabled materials use ordinary theme surfaces. Existing
  compatibility-mode selections migrate automatically.
- Expanded plugin panels adapt to the window height and align nearby column bottoms.
- Plugin panels expand, collapse and switch smoothly with rotating indicators.
  ThemeModifier provides a reduced interface motion preference.
- Clicking a tag filters by that tag in Details and Grid Details.

The theme includes expansion indicator motion, basic panel entrance effects,
viewport height limits and manual Hero media controls. Screenshot and video
content still require the relevant media extensions.

For realtime glass, precise panel alignment, continuous panel transitions,
enhanced media previews and automatic playback, also install Dune Materials
0.6.8 and restart Playnite.
Automatic Hero slideshow/video playback remains off by default. If you prefer
ordinary surfaces, disable realtime materials in the extension settings.
