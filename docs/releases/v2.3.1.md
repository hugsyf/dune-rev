# Dune Rev 2.3.1

Fixes tag filtering in Details and Grid Details views. Clicking a game's tag now filters the library by that tag correctly, resolving [#7](https://github.com/hugsyf/dune-rev/issues/7).

Requires Playnite 10.57 or newer. Download and open the `.pthm` file to install.

## 简体中文

修复详情视图与网格详情视图中点击标签后筛选失败的问题。现在点击游戏标签即可正确筛选游戏库。

需要 Playnite 10.57 或更新版本。下载并打开 `.pthm` 文件即可安装。
