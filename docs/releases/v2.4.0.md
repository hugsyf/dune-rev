# Dune Rev 2.4.0

Dune Rev 2.4.0 updates controls across the theme and adds built-in Hero media
controls, basic panel motion and cover banners that keep their image proportions.

## Changes

- Use consistent spacing, rounded corners, hover states, selection and keyboard
  focus across menus, dropdowns, tooltips, lists, tables and navigation controls.
- Match text, password, numeric, date and path inputs. Standard buttons and inputs
  use a 32 DIP minimum height. Keep compact icon buttons and multiline editors.
- Add table sort indicators, clearer input validation and larger slider handles.
- Select Hero backgrounds, store screenshots and video without Dune Materials.
  Browse screenshots, open the gallery, and use video play, pause and mute controls.
- Rotate expansion indicators and add light panel entrance effects. Limit expanded
  panels to the viewport and keep short DLC lists compact. Respect reduced motion.
- Scale platform and store banners with the cover width without stretching them.
- Refine Hero layout, media placement and detail-page scrolling.

## Install

Requires **Playnite 10.57 or newer**. Download and open the `.pthm` asset, then
select **Dune Rev** in Playnite's Desktop theme settings. Existing users can also
check for theme updates in Playnite.

This release contains the theme package. **Dune Materials / Helper is optional
and is not included.** Settings continue to use ThemeModifier. Store screenshots
require Steam Store Screenshots Viewer; video and logos require Extra Metadata
Loader. Other addon panels appear when their providers have data.

If you used the earlier Dune Materials preview, disable that preview extension
before using this standalone stable release. Realtime glass, continuous panel
transitions, enhanced video previews and automatic playback remain in development.

## 简体中文

### 更新内容

- 统一菜单、下拉框、提示框、列表、表格及导航控件的间距、圆角、悬停、选中和键盘焦点反馈。
- 统一文本、密码、数值、日期及路径输入框。普通按钮和输入框采用 32 DIP 最小高度，保留紧凑图标按钮与多行编辑框。
- 添加表格排序指示、清晰的输入错误反馈，并增大滑块拖动目标。
- 主题内置 Hero 背景、商店截图与视频切换，支持截图翻页、打开图库、视频播放／暂停及静音。
- 展开箭头旋转并加入轻量内容入场效果。展开区受视口高度限制，短 DLC 列表按内容收缩，并遵守减少动效设置。
- 平台与商店横幅随封面宽度等比例缩放。
- 改进 Hero 布局、媒体控件位置和详情页滚动。

### 安装

需要 **Playnite 10.57 或更新版本**。下载并打开 `.pthm` 文件，然后在桌面主题设置中选择 **Dune Rev**。
已有用户也可以在 Playnite 中检查主题更新。

本次发布提供主题安装包，**无需安装 Dune Materials / Helper**。主题设置继续使用 ThemeModifier。
商店截图需要 Steam Store Screenshots Viewer，视频及 Logo 需要 Extra Metadata Loader。
其他插件面板按已安装扩展与游戏数据提供内容。

此前使用过 Dune Materials 预览扩展的用户，请先停用该预览扩展，再使用本正式版。
实时玻璃、连续展开过渡、增强视频预览与自动播放功能仍在开发中。
