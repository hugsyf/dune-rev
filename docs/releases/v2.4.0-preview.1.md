# Dune Rev 2.4.0 Preview 1 + Dune Materials 0.5.0

This is an opt-in preview. The stable release remains 2.3.0.

## Install

1. Install `DuneMaterials-0.5.0.pext` and `DuneRev-2.4.0-preview.1.pthm` from this release.
2. Restart Playnite after installing both packages and select **Dune Rev** in Desktop theme settings.
3. Open **Add-ons → Extension settings → Generic → Dune Materials**. New installations use **enhanced materials → Realtime** by default. Existing preferences are retained: enable enhanced materials and select Realtime if needed.
4. Enable the theme's material switch in ThemeModifier if it was previously disabled.

The theme also works without Dune Materials, with ordinary fallback surfaces.
ThemeModifier controls appearance/layout; Dune Materials controls the material mode.

## What changed

- Shared window background and translucent surfaces, with a realtime material renderer and a cached compatibility fallback. Menus retain stronger tint for readability.
- Consistent card spacing, expandable plugin panels, rounded Hero clipping, and smoother integration of the top bar and filter pane.
- Hero selection for native game background, Steam store screenshots and Extra Metadata Loader video. Available video is preferred, followed by screenshots, then native background.
- Screenshot side previews, an independent video thumbnail, and playback/mute/repeat controls above the media tiles. Automatic slideshow/playback stays off by default; automatically started video begins muted.
- Clearer material settings, English/Chinese labels, recommended defaults and collapsed diagnostics. Existing preferences are preserved.
- Consolidated theme generation and a release build that verifies versions, packaged files and SHA-256 checksums.

## Optional extensions

- **ThemeModifier:** theme colors, layout and material switch.
- **Steam Screenshots:** Hero store screenshots and the store screenshot tab.
- **Extra Metadata Loader:** game logos and Hero video, when media is available.
- Achievement, activity, requirements and other supported plugins remain optional. Missing plugins do not require selecting a different theme package.

## Preview notes and feedback

Realtime has been smooth in the author's tested setup; this is not a guarantee for all hardware. Try **Compatibility (cached)** if you encounter stuttering or display issues. Unsupported realtime sources/hardware use the fallback path. Diagnostics report UI update timing, not frame rate or GPU performance.

When reporting an issue, include Playnite/theme/extension versions, Windows display scaling, the affected view, relevant plugins, a screenshot and the expanded Dune Materials diagnostics. Remove private information before sharing.

No automated WPF rendering or Playnite automation was used for this release. Compilation, bilingual settings checks and package verification passed. The material lifecycle/layout suite passed on the preceding 0.4.11 build; its final 0.5.0 rerun was blocked because the local check executable was inaccessible/locked, so a fresh pass of that suite is not claimed. Wider Playnite testing is the purpose of this preview.

To return to stable: install the 2.3.0 theme from its release page, disable Dune Materials, and restart Playnite. Stable 2.3.0 does not need the material extension.

## 中文安装与说明

这是需要主动下载安装的预览版，稳定版仍为 **2.3.0**。

1. 安装本页的 **DuneMaterials-0.5.0.pext** 与 **DuneRev-2.4.0-preview.1.pthm**。
2. 两个包安装完毕后重启 Playnite，在桌面主题设置中选择 **Dune Rev**。
3. 在「附加组件 → 扩展设置 → 通用 → Dune Materials」中检查设置。新安装默认启用增强材质和实时模式；已有用户的设置会保留，必要时手动开启。
4. 如果之前关闭了 ThemeModifier 中的主题材质总开关，请重新开启。

**主要变化：** 全局背景与卡片共享材质场景、实时材质与兼容回退、统一间距和圆角、Hero 背景／商店截图／视频切换，以及缩略框上方的播放、声音和自动轮播按钮。自动轮播／播放默认关闭。

**设置分工：** ThemeModifier 调整主题外观与布局，Dune Materials 选择材质模式。未安装材质扩展也能使用主题的常规回退表面。Steam Screenshots 提供商店截图，Extra Metadata Loader 提供 Logo／视频；其他内容插件同样可选。

当前实机反馈流畅，但尚未覆盖所有硬件。遇到卡顿或显示问题时可切换「兼容（静态缓存）」。反馈请附版本、缩放比例、视图、相关插件、截图及诊断信息；诊断耗时不等于帧率。本次编译、中英文设置检查及安装包核对已通过；材质生命周期／布局检查此前在 0.4.11 通过，但最终复跑因本机检查程序无法访问／被占用而受阻，不宣称该套检查在 0.5.0 已重新通过。未执行 WPF 渲染检查或自动操作 Playnite，预览版用于收集更多实机反馈。

如需回退：安装 2.3.0 稳定版主题、禁用 Dune Materials 并重启 Playnite。
