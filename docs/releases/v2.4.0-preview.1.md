# Dune Rev 2.4.0 Preview 1

## What's new

- Translucent materials that let the game background show through cards and controls, with matching top bar and filter pane styling.
- A Hero media selector for game backgrounds, store screenshots and videos, with screenshot side previews and playback controls above the thumbnails.
- Improved card spacing, rounded Hero corners and expandable plugin panels.
- Updated material settings with English/Chinese labels and a recommended configuration.

## Install

Download and install both **DuneRev-2.4.0-preview.1.pthm** and **DuneMaterials-0.5.0.pext**, then restart Playnite and select **Dune Rev** in Desktop theme settings.

New installations enable realtime materials automatically. Existing users can enable enhanced materials and select **Realtime** under **Add-ons → Extension settings → Generic → Dune Materials**. Check the theme material switch in ThemeModifier if materials were previously disabled.

## Optional extensions

- **ThemeModifier:** appearance and layout settings.
- **Steam Screenshots:** store screenshots in the Hero and screenshot tab.
- **Extra Metadata Loader:** game logos and Hero videos.

The theme remains usable without these extensions. Automatic slideshow/video playback is off by default; use the repeat button above the thumbnails to enable it.

## Feedback

If you encounter stuttering or display issues, try **Compatibility (cached)** in Dune Materials. Please report issues with a screenshot, the affected view, and your theme, extension and Playnite versions.

To return to stable, install the **2.3.0** theme, disable Dune Materials and restart Playnite.

## 中文说明

### 新增与改进

- 新增半透明材质，让游戏背景自然透过卡片和控件，并统一顶栏、筛选栏的风格。
- Hero 支持切换游戏背景、商店截图和视频，提供截图侧边预览，播放控制位于缩略框上方。
- 完善卡片间距、Hero 圆角和插件展开面板。
- 整理材质设置，提供中英文界面和推荐配置。

### 安装

下载安装本页的 **DuneRev-2.4.0-preview.1.pthm** 和 **DuneMaterials-0.5.0.pext**，然后重启 Playnite，在桌面主题设置中选择 **Dune Rev**。

新安装默认启用实时材质。已有用户可以在「附加组件 → 扩展设置 → 通用 → Dune Materials」中开启增强材质并选择「实时」。如果此前关闭了 ThemeModifier 中的主题材质开关，请重新开启。

### 可选插件

- **ThemeModifier**：调整主题外观与布局。
- **Steam Screenshots**：提供 Hero 商店截图和截图页签。
- **Extra Metadata Loader**：提供游戏 Logo 和 Hero 视频。

缺少这些插件时仍可使用主题。自动轮播／播放默认关闭，可通过缩略框上方的循环按钮开启。

### 问题反馈

遇到卡顿或显示异常时，可以先在 Dune Materials 中尝试「兼容（静态缓存）」。反馈问题时请附截图、出现问题的视图，以及主题、扩展和 Playnite 版本。

如需回退，可安装 **2.3.0** 稳定版主题、禁用 Dune Materials 并重启 Playnite。
